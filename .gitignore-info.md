# .gitignore Configuration

## Files Excluded from Git

This document explains what files are excluded from version control and why.

### Story/Task/Epic Tracking Documents

The following patterns are ignored (internal use only, not pushed to repository):

```
**/STORY_*.md          # Story completion/breakdown docs (e.g., STORY_2.1_COMPLETE.md)
**/EPIC_*.md           # Epic tracking documents
**/TASK_*.md           # Task breakdown documents
**/*_BREAKDOWN.md      # Any breakdown documents (e.g., STORY_2.2_BREAKDOWN.md)
**/*_COMPLETE.md       # Any completion documents (e.g., STORY_1.1_COMPLETE.md)
SETUP_COMPLETE.md      # Setup completion docs
```

**Why**: These are internal tracking documents for development workflow and don't need to be in the repository.

**Examples of ignored files**:
- `ml/STORY_2.1_COMPLETE.md`
- `ml/STORY_2.2_BREAKDOWN.md`
- `backend/SETUP_COMPLETE.md`
- `backend/STORY_1.2_COMPLETE.md`

### Project Documentation (Also Ignored)

```
SDS.md                 # Software Design Specification
PROJECT_BACKLOG.md     # Project backlog
PROJECT_BACKLOG.csv    # Backlog CSV export
PROGRESS.md            # Development progress tracking
```

**Why**: These are project planning documents that may contain sensitive information or are managed separately.

### ML Models & Data

```
*.pkl, *.joblib        # Model artifacts (too large for git)
*.csv, *.parquet       # Data files (too large for git)
data/, datasets/       # Data directories
```

**Why**: Model files and datasets are typically large and should be stored in model registries or data storage (not git).

### Standard Exclusions

- Python cache (`__pycache__/`, `*.pyc`)
- Virtual environments (`venv/`, `env/`)
- Environment variables (`.env`, `.env.local`)
- IDE files (`.vscode/`, `.idea/`)
- Jupyter checkpoints (`.ipynb_checkpoints`)
- Logs (`*.log`, `logs/`)
- Test coverage (`htmlcov/`, `.coverage`)

## What IS Tracked in Git

✅ **Source code**: All `.py` files
✅ **Configuration**: `requirements.txt`, `.env.example`
✅ **Documentation**: `README.md` files in each directory
✅ **Tests**: All test files in `tests/` directories
✅ **Notebooks**: `.ipynb` files (for data exploration, examples)

## Verifying What's Ignored

Check if a file is ignored:
```bash
git check-ignore -v path/to/file.md
```

See all ignored files in a directory:
```bash
git status --ignored
```

## Adding Files Back

If you need to track a previously ignored file:
```bash
git add -f path/to/file.md
```

Or update `.gitignore` to remove the pattern.

---

**Note**: If you've already committed tracking documents, you'll need to remove them from git history:
```bash
git rm --cached path/to/STORY_*.md
git commit -m "Remove tracking documents from git"
```
